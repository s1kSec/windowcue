# WindowCue

`WindowCue` 是一个基于 `.NET 8 + WPF + Win32 P/Invoke + DWM Thumbnail API` 的窗口快捷键绑定器。

## 发布版本

- `WindowCue_CN.exe`：中文界面
- `WindowCue_EN.exe`：英文界面

两个版本使用相同功能和配置格式，运行环境需要 Windows 10/11 x64 与 .NET 8 Desktop Runtime。

## 功能

- 每 0.5 秒扫描一次前台 WindowCue 界面的窗口列表；
- 包含正常、后台、最小化以及 Win+D 后仍然存在的用户顶层窗口；
- 过滤子窗口、禁用窗口、工具窗口及无法解析到应用进程的系统辅助窗口；
- 最小化窗口不再使用任务栏图标矩形做尺寸过滤，Win+D 后仍能完整保留；
- 对打包应用的 `ApplicationFrameHost`/应用进程同标题窗口进行解析与去重；
- 显示应用图标及 DWM 实时窗口预览；
- 可为多个窗口分别绑定不同的全局快捷键，例如 `Alt+C` 对应 VS Code、`Alt+V` 对应 Chrome；
- 录入期间临时注销全部已绑定快捷键，防止其他目标窗口被意外唤醒；
- 每个已绑定窗口都使用浅绿色边框标记；
- 目标位于前台时按快捷键最小化，否则恢复、置前并获取焦点；
- 任一目标 HWND 消失时，只注销并删除该窗口对应的失效绑定；
- “绑定”成功后按钮切换为“取消绑定”，两种操作共用同一个按钮；
- 点击“绑定”后保留当前设置界面，右上角关闭或最小化时进入系统托盘；
- 窗口高度由卡片内容自适应，受当前显示器工作区高度限制，超限后列表内部滚动；
- 使用与客户区相同颜色的自绘标题栏。

## 使用

1. 运行中文或英文版本。
2. 在实时预览列表里选择目标窗口。
3. 点击快捷键输入框并按下组合键，例如 `Ctrl + Alt + G`。
4. 点击“绑定”或 “Bind”，按钮会切换为“取消绑定”或 “Unbind”。
5. 继续选择其他窗口并录入其他快捷键，可同时保存多条绑定。
6. 使用各自快捷键显示或最小化对应窗口。

双击托盘图标可重新打开设置，右键托盘图标可打开设置或退出。

多绑定配置保存在 `%LocalAppData%\WindowCue\bindings.json`；旧版 `binding.json` 会在首次启动时自动迁移。

## 构建

在本目录运行：

```powershell
.\build.ps1
```

发布结果：

```text
..\dist\WindowCue\WindowCue_CN.exe
..\dist\WindowCue\WindowCue_EN.exe
```

应用图标源文件与多尺寸 ICO 位于 `Assets` 目录。ICO 包含 16、24、32、48、64、128 和 256 像素版本。
